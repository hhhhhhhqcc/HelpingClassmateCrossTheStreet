- 交付 EXE：106496 字节。
- SHA-256：44931f0fbd61ca0dfa9f561a56c8dfb0f7188757ef396d84d87934a589b2eb2e。
- 200 个方法、212 个字段；199 个托管方法的控制流与求值栈检查通过，另一个方法为系统键盘 PInvoke。
- 86 个外部框架成员引用与系统真实 .NET Framework 元数据签名匹配，17 项 PE/CLR 启动结构检查通过。
