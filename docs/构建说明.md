# 构建说明

使用 Node.js 20 或更新版本。在仓库根目录执行：

```powershell
npm test
npm run build
```

构建与逻辑检查只使用 Node.js 内置模块，不需要安装依赖。输出在 dist/同学别刷了_街头行动版/，同时生成同名 ZIP。也可使用 node scripts/build.mjs <输出目录> 指定位置。

游戏运行需要 Windows 和 .NET Framework 4.x；构建可以在其他系统运行，构建过程不会启动游戏。

src/native/ 下的 .cs 是项目自带编译器支持的 C# 子集。build-game.mjs 依次组合游戏、路线、道具、绘图和动作模块，同名方法由后载入的实现覆盖。compile-subset.mjs 与 build-managed.mjs 生成 .NET CIL 和 PE 程序，host-native-action-v2.mjs 提供 WinForms 窗口、绘图、输入、音效与全屏。

美术资源与音效包含在 game/assets/。generate-motion-audio.mjs 可以重新生成 WAV。generate-visual-assets.mjs 可以重新生成 PNG/ICO，此可选操作需要自行安装 sharp；正常构建使用已提交的资源，不需要 sharp。

npm test 验证 CIL 控制流、路线、装备组合、道路、动作和界面绘图。检查使用逻辑模拟器，不会启动桌面游戏，不测量实际帧率。Windows 框架签名的独立核对模块为 verify-binary.mjs；现有验证范围见 [验证说明](验证说明.md)。
