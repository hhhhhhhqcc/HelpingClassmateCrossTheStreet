# 同学，别刷了！——街头行动版

先将 ZIP 整体解压，进入「同学别刷了_街头行动版」文件夹，双击「同学别刷了.exe」运行。请保留与程序同目录的 assets 文件夹，城市插画、道具图标与窗口图标会从这里加载。

这是 Windows 桌面游戏，使用原生窗口与 GDI+ 绘制，无需浏览器或联网。

街头行动版增加了连续动作与即时反馈：人物步态、身体起伏、朝向与手机刷屏，车轮与速度线，道具扩散波纹、冲刺残影、粒子和受撞镜头反馈。菜单车流、无人机和地图路线也会持续运动。

移动现在有短暂加速与刹停。Shift 向当前移动方向短冲刺，松开方向键时按上次朝向冲刺；消耗 18 体力、冷却 1.4 秒。牵手时同学跟着一起冲刺，需要观察车流，碰撞仍会扣生命。

移动中贴近车辆但没有相撞，并且等它安全通过后，会触发惊险闪避：获得 15 分、2 金币、6 体力（不超过上限），每辆车只结算一次；停车装置中的车辆不能用来刷奖励。该奖励仅用于单人旅程。

V 开关声音，F11 进入或退出全屏。暂停或查看背包时，道路、冲刺冷却、粒子和道具时间冻结。音效存放在 assets/audio，请连同图片资源保留。

支持 Windows 10/11，使用系统 .NET Framework 4.x（通常已自带）。

## 单人：三幕回家旅程

先选一件起始装备，再从地图规划路线。整趟旅程有三幕，每幕六站；每层三条路线，从上一站只能走向相邻列。各幕最后汇入特殊大路口。

地图包含六类节点：

| 节点 | 内容 |
| --- | --- |
| 护送路段 | 两人一起到对岸，获得金币和三选一装备 |
| 精英路口 | 更密集的车流，通关金币更多 |
| 街头事件 | 根据已展示的收益和代价选择行动 |
| 便利商店 | 花金币买未拥有的装备，可以连续购买 |
| 安全驿站 | 恢复生命、赚金币、领取已展示装备，三选一 |
| 区域首领 | 挑战本幕的特殊大路口，之后进入下一幕 |

三种特殊大路口有不同规则：校门车队会提前预告提速波次；施工绕行要求从隔离带两侧通过；连播路口的车道交替通行，同学也会出现有预告的分心。

生命、金币和装备在旅程中保留，受伤会回到最近通过的安全岛。同学仍会停下、乱走或倒退，牵手、口哨和引导装置可以帮助他过马路。

地图、事件、商店、休息点以及背包界面不会推进道路时间。关闭程序会结束当前旅程；未完成的进度不会保存到磁盘。

## 独有装备与搭配

单人共有 24 件装备，每种最多获得一件。被动装备取得后自动生效，主动道具按对应键使用；没有等级或重复升级。奖励和商店只提供未拥有的装备；本次候选不足时会提供补给。

Q / F / R 对应慢时钟、反光伞和奶茶。新增四种 T 装置：折叠路障、信号遥控器、奶茶诱饵、玩具无人机。Tab 在已拥有的装置之间轮换，T 使用当前装置；四种装置共享冷却，轮换不会清除冷却。

B 打开搭配图鉴与背包，Tab 切换两个页面类型，左右键翻页。组合图鉴三页，装备背包两页，能够查看全部配方、效果和拥有状态。

| 场景 / 玩家 | 操作 | 按键 |
| --- | --- | --- |

| 地图 | 左 / 中 / 右路线 | 1 / 2 / 3 直接前往，或左右键选择后 Enter |
| 装备 / 事件 / 休息 | 三选一 | 1 / 2 / 3，或左右键 + Enter，或鼠标 |
| 商店 | 购买 / 离开 | 1 / 2 / 3 或左右键 + Enter 购买，0 离开 |
| 1P | 移动 | W / A / S / D，单人也支持方向键 |
| 1P | 牵手 / 口哨 | 按住空格 / E |
| 1P | 短冲刺，18 体力 / 1.4 秒冷却 | Shift |
| 1P | 慢时 / 伞 / 奶茶 | Q / F / R，需先获得 |
| 单人 | 当前装置 / 轮换装置 | T / Tab |
| 单人 | 图鉴与背包 / 切换 / 返回 | B / Tab / B 或 Esc，也可点击返回按钮 |
| 公共 | 暂停 / 恢复，菜单 | P 或 Esc，M |
| 公共 | 声音 / 全屏 | V / F11 |

窗口失去焦点时，道路会自动暂停，回来后按 Enter 或 P 恢复。鼠标支持菜单、地图节点、选项卡、商店离开和图鉴分页按钮。

## 双人对抗

保留同一键盘的双人对抗，每局 75 秒，先赢两局获胜。1P 带双方到对岸即可获胜；超时或 1P 生命耗尽则 2P 获胜。

2P 使用方向键移动，Enter 挣脱，获得对应道具后用 J 假通知、K 横滑闪避、L 耳机。2P 被车撞会扣能量并短暂眩晕。

双人也取消了装备升级：1P 保留 12 件独有装备，2P 保留 8 件独有装备。单人的分岔地图、T 装置和 B 图鉴属于单人旅程。
